# Kevin Heavey's blog

This is a small Jekyll blog published by GitHub Pages at https://kevinheavey.dev.

## Add a post

Create a Markdown file in `_posts` named `YYYY-MM-DD-post-title.md`:

```markdown
---
layout: post
title: "Post title"
description: "A short description for search results and feeds."
image: "/assets/your-post-preview.png" # optional; use a 1200×630 PNG
---

Write your post here in Markdown.
```

Commit it to `main`. GitHub Pages will rebuild the site. Posts appear newest first on the homepage and in the Atom feed.
